## Spacing Scale

All spacing uses existing `$space-*` tokens from `_sass/_variables.scss`. Do NOT introduce new spacing values.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| `$space-1` | 0.25rem (4px) | Icon gaps, inline padding |
| `$space-2` | 0.5rem (8px) | Compact element spacing, `.highlight-label` margin-bottom |
| `$space-3` | 0.75rem (12px) | Internal caption spacing |
| `$space-4` | 1rem (16px) | Grid gap, highlight-item padding, accent bar horizontal padding |
| `$space-6` | 1.5rem (24px) | Section margins, hero-thesis margin-bottom, paper entry padding-top/bottom |
| `$space-8` | 2rem (32px) | Major section separation, grid margin-bottom |

## Typography

All type tokens from `_sass/_variables.scss`. Do NOT introduce new size values.

Exactly 4 sizes declared in this spec. Exactly 2 weights used.

| Role | Token / Value | Weight | Line Height | Font | Usage |
|------|--------------|--------|-------------|------|-------|
| Label | `$text-caption-size` = 0.75rem (12px) | 600 | `$text-caption-line-height` = 1.4 | `var(--font-sans)` Inter | `.highlight-label` (uppercase, letter-spacing 0.08em); author lines in `.selected-papers-showcase`; venue text (`.periodical`) |
| Body | `$text-body-size` = 1rem (16px) | 400 | `$text-body-line-height` = 1.65 | `var(--font-sans)` Inter | Bio paragraphs, highlight item body |
| Title (paper) | `$text-title-3` = 1.125rem (18px) | 600 | 1.3 | `var(--font-serif)` Source Serif 4 | Paper `.title` within `.selected-papers-showcase` — increased prominence per D-05 |
| Hero | `clamp(1.2rem, 2.2vw, 1.55rem)` | 400 | 1.45 | `var(--font-sans)` Inter | `.hero-thesis` — already declared in `_base.scss`, do not re-declare |

Section headings (`h2` at `$text-title-2` = 1.5rem/24px, weight 400–600): inherited from existing `h2` rule in `_base.scss`. Not re-declared in this spec — the 4-size limit is maintained by treating it as a site-level inherited style.

**Weight pairing: {400, 600} — Option A.**
- Weight 400: body text, hero text, author lines, venue text.
- Weight 600: paper titles, `.highlight-label`. The uppercase + `letter-spacing: 0.08em` on `.highlight-label` provides additional visual differentiation beyond weight alone.
- Weight 700 is NOT used anywhere in this phase.

**Paper title specifics (critical for D-05 — increased prominence):**
- Font family: `var(--font-serif)` (Source Serif 4)
- Font size: `$text-title-3` = 1.125rem
- Font weight: 600
- Color: `var(--global-text-color)`
- This overrides bib.liquid's default `.title` styling within the showcase wrapper only.

**Author line specifics (critical for D-05 — less dominant):**
- Font size: `$text-caption-size` = 0.75rem (12px)
- Font weight: 400
- Color: `var(--global-text-color-light)` — muted, not primary text color

**Venue badge specifics (critical for D-05 — reduced noise):**
- `.periodical` font size: `$text-caption-size` = 0.75rem (12px)
- Color: `var(--global-text-color-light)`
- No bold weight — weight 400 only
- No border or background — plain text, no badge styling within showcase

## Layout Contracts

### Section Order in `_pages/about.md` (D-01)

New order within the `{{ content }}` block:

1. `.hero-thesis` paragraph — stays at top (no change)
2. Bio paragraphs (two `<p>` tags) — move above `.homepage-highlights`
3. `.homepage-highlights` grid — moves below bio

Current order: hero-thesis → highlights → bio. Target order: hero-thesis → bio → highlights.

**Implementation:** Edit `_pages/about.md` only. The bio paragraphs (currently lines 37–44) move above the `.homepage-highlights` div (currently lines 22–35). Do not touch `_layouts/about.liquid` for this change.

### Subtitle Change in `_pages/about.md` front matter (D-03)

Change:
```yaml
subtitle: Researcher at <a href='https://www.fbk.eu/en/'>Fondazione Bruno Kessler</a>.
```

To:
```yaml
subtitle: "NLP Researcher · FBK"
```

The middle dot `·` (U+00B7, MIDDLE DOT) is the required separator. Do not use a comma, dash, or bullet. No HTML link — plain text only.

### Highlights Grid: 2-column → 3-column (D-07)

In `_sass/_base.scss`, change the `.homepage-highlights` rule:

```scss
// Before:
grid-template-columns: repeat(2, minmax(0, 1fr));

// After:
grid-template-columns: repeat(3, minmax(0, 1fr));
```

Only this one line changes. All other `.homepage-highlights` properties (`gap: $space-4`, `margin: $space-6 0 $space-8`) stay unchanged.

**Mobile behavior (Claude's Discretion):**
- Below 576px: stack to 1 column — `grid-template-columns: 1fr`
- 576px–767px: 2 columns — `grid-template-columns: repeat(2, minmax(0, 1fr))`
- 768px+: 3 columns — `grid-template-columns: repeat(3, minmax(0, 1fr))`

Use existing `@media (min-width: 576px)` and `@media (min-width: 768px)` breakpoints matching al-folio's Bootstrap breakpoints.

### Selected Papers Showcase Wrapper (D-04)

In `_layouts/about.liquid`, wrap the selected papers include:

```liquid
<!-- Selected papers -->
{% if page.selected_papers %}
  <h2>
    <a href="{{ '/publications/' | relative_url }}" class="section-link">Main publications</a>
  </h2>
  <div class="selected-papers-showcase">
    {% include selected_papers.liquid %}
  </div>
{% endif %}
```

`selected_papers.liquid` is read-only. The wrapper `<div class="selected-papers-showcase">` goes in `about.liquid` only.

Note: `selected_papers.liquid` renders `<div class="publications">` containing jekyll-scholar's `{% bibliography %}` output. The root list element is `<ol class="bibliography">`. Each entry is an `<li>` containing a `<div class="row">`.

## Selected Papers Showcase — SCSS Contract

### Selector Hierarchy (derived from bib.liquid source — read-only)

```
.selected-papers-showcase
  .publications                          ← rendered by selected_papers.liquid
    ol.bibliography                      ← jekyll-scholar root list
      li                                 ← one paper entry
        .row
          .col-sm-10 (or .col-sm-8)     ← main content column
            .title                       ← paper title
            .author                      ← author line
            .periodical                  ← venue + year (appears twice: journal/conf + note)
            .links.links-primary         ← PDF, DOI, Code buttons
            .links.links-secondary       ← Abstract, arXiv, Bib buttons
```

### SCSS Block to Add in `_sass/_base.scss`

Write as a single nested block. All selectors are prefixed with `.selected-papers-showcase` to avoid leaking into the publications page.

```scss
// ─── Selected Papers Showcase (Phase 2, D-04/D-05) ───────────────────────────
// Targets bib.liquid HTML output within the homepage showcase wrapper only.
// bib.liquid is read-only — do not modify it. Selectors derived from its output.

.selected-papers-showcase {
  .publications {
    margin-bottom: 0;
  }

  ol.bibliography {
    list-style: none;
    padding-left: 0;
    margin-bottom: 0;
  }

  ol.bibliography li {
    position: relative;
    padding: $space-6 $space-4 $space-6 calc(#{$space-4} + 4px);
    border-bottom: 1px solid var(--global-divider-color);
    border-left: 3px solid var(--global-theme-color);
    margin-left: 0;

    &:last-child {
      border-bottom: none;
    }
  }

  // Title — increased prominence (D-05)
  // Weight 600, serif, 1.125rem — differentiated from body (400, sans, 1rem)
  ol.bibliography li .title {
    font-family: var(--font-serif);
    font-size: $text-title-3;   // 1.125rem / 18px
    font-weight: 600;
    line-height: 1.3;
    color: var(--global-text-color);
    margin-bottom: $space-2;
  }

  // Author line — less dominant (D-05)
  // Uses caption size (0.75rem/12px) and weight 400; muted color
  ol.bibliography li .author {
    font-size: $text-caption-size;   // 0.75rem / 12px
    font-weight: 400;
    color: var(--global-text-color-light);
    margin-bottom: $space-2;
  }

  // Venue / year — reduced noise (D-05)
  // Same caption size and muted color as author lines
  ol.bibliography li .periodical {
    font-size: $text-caption-size;  // 0.75rem / 12px
    font-weight: 400;
    color: var(--global-text-color-light);
    margin-bottom: $space-2;

    em {
      font-style: normal;  // bib.liquid wraps journal/booktitle in <em>; neutralise here
      color: var(--global-text-color-light);
    }
  }

  // abbr venue badge — suppress or minimise (D-05, reduce noise)
  ol.bibliography li abbr.badge {
    display: none;  // hide venue badge within showcase; visible on full publications page
  }

  // Links row — keep compact
  ol.bibliography li .links {
    margin-top: $space-2;
  }

  // Bootstrap .row inside li — remove default gutters
  ol.bibliography li .row {
    margin-left: 0;
    margin-right: 0;
  }

  ol.bibliography li .col-sm-10,
  ol.bibliography li .col-sm-8 {
    padding-left: 0;
  }
}
```

### Accent Bar Specification

- Width: 3px solid
- Token: `border-left: 3px solid var(--global-theme-color)`
- Runs the full height of each `li` element
- Left padding of the content column: `calc($space-4 + 4px)` = `calc(1rem + 4px)` — provides visual gap between bar and text

### Mobile Behavior for Showcase

The showcase is a single-column list at all breakpoints — no grid, no columns. No mobile-specific overrides needed for the paper list itself.

Below 576px: add `padding: $space-4 $space-3 $space-4 calc(#{$space-3} + 4px)` to reduce horizontal padding on small screens:

```scss
@media (max-width: 575.98px) {
  .selected-papers-showcase ol.bibliography li {
    padding: $space-4 $space-3 $space-4 calc(#{$space-3} + 4px);
  }
}
```
