<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Google Fonts CDN | `<link rel="stylesheet">` to `fonts.googleapis.com` is an external dependency; CDN downtime would degrade typography |
| Build pipeline → static asset | Jekyll emits the `<link>` tag from `_config.yml`; malformed YAML breaks the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | `_config.yml` `google_fonts.url.fonts` value | accept | Static repo file under git; tampering requires repository write access — out of scope for ASVS L1 on a public personal site. |
| T-01-02-02 | Information Disclosure | Google Fonts request leaks visitor IP/UA to Google | accept | Standard, public-fonts CDN behavior; no PII transmitted beyond what every web request emits. al-folio sites already used Google Fonts (Roboto) — no privacy regression. |
| T-01-02-03 | Denial of Service | Google Fonts CDN outage | mitigate | Font stacks include system fallbacks: `system-ui, -apple-system, sans-serif` and `Georgia, serif`. If Google Fonts fails to load, body still renders in a system sans and headings in Georgia. |
| T-01-02-04 | Denial of Service | YAML parse error from malformed Google Fonts URL value | mitigate | The URL is wrapped in double quotes (preserved by Jekyll YAML parser). `bundle exec jekyll build` is the gate — must succeed before plan completion. |
| T-01-02-05 | Tampering | Subresource integrity not enforced on `<link>` tag (a compromised CDN could inject malicious CSS) | accept | al-folio template default — SRI is not currently set on any third-party stylesheet. Adding SRI is out of scope for Phase 1 and should be considered as a separate Phase 4 (QUAL-*) hardening item. |

No high-severity threats. ASVS L1 satisfied by build-pipeline gate (T-01-02-04) and fallback typography (T-01-02-03).
</threat_model>
